# Android プロジェクト一式（無料枠 Gemini API ＋ ローカルAI ハイブリッド対応）

GitHub Actions クラウドビルドで APK を生成でき、**無料枠 Gemini API（スターレンタルサーバー中継）** と **ローカルAI（端末内 Termux/Ollama/llama.cpp または同一LAN PC）** の両方を切り替え・自動フォールバックできる構成です。

## 4つのAI動作モード
1. **ハイブリッド（無料枠Gemini優先 → ローカルAI）**：通常は無料枠 Gemini API で応答し、無料枠上限（429）やオフライン時は自動的にローカルAIへ切り替えます。
2. **ハイブリッド（ローカルAI優先 → 無料枠Gemini）**：まずローカルAIで高速・完全無料で応答し、ローカルAIが起動していない時だけ Gemini API を使います。
3. **無料枠 Gemini API のみ**：スターレンタルサーバー経由の Gemini API のみを使用します。
4. **ローカルAI のみ**：外部通信なしで端末内またはLAN内のローカルAIのみで完結します。
